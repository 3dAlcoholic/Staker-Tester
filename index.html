Check a token's pair on a router

For a VRouter, checks the V1/V2 pair only. For a V3 or V3_2 router, checks the V1/V2 pair plus every V3 fee tier (0.01%, 0.05%, 0.25%, 0.3%, 1%, 2%) — and shows liquidity (priced via WPLS/stablecoin) for any pool that's actually seeded. Found the right one? Hit "Use for reward token" to send the token, router, and fee tier straight down to the Add form below — no need to remember it.

Add a reward token

Use 0x0 (or the toggle below) to add a native PLS slice. For any other token, pick which registered router has a live WPLS pair for it — or use "Use for reward token" above to fill this in automatically.
